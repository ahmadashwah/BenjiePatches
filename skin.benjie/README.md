# Benjie 2.0 (skin.benjie)

Kodi skin with Netflix layout.

**Benjie is a modified version of Bingie by matke (skin.bingie 2.0.2).** All credit for the original skin, its design and
artwork goes to the Bingie authors. Benjie only adds the changes listed in
[CHANGES.md](CHANGES.md), which used to be applied to Bingie at runtime by the
IPTV Helper Fixes add-on (`service.iptvhelperfixes`).
