BenjiePatches

Install repository.benjie from zip, then Install from repository → Bengie Repository → Look and feel → Skin → Bengie 2.0. Kodi installs everything else with it.

  • repository.benjie-1.0.1.zip

Bengie 2.0 is a modified version of the Bingie skin by matke (GPL v2). The Bengie builds of XStream Player (MIT), TMDb Bingie Helper (GPL-3.0) and Bingie Widgets (GPL v2) credit their original authors. Source: github.com/ahmadashwah/BenjiePatches.
