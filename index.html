BenjiePatches

Install repository.benjie from zip, then Install from repository → Benjie Repository → Look and feel → Skin → Benjie 2.0. Kodi installs everything else with it.

  • repository.benjie-1.0.0.zip (the Benjie repository: install this first)
  • repo/ (what the repository serves)
  • service.iptvhelperfixes190.zip (for the Update entry on devices set up before the repository)
  • skin.benjie-2.0.2.2.zip (the skin on its own)

Benjie 2.0 is a modified version of the Bingie skin by matke (GPL v2). The Benjie builds of XStream Player (MIT), TMDb Bingie Helper (GPL-3.0) and Bingie Widgets (GPL v2) credit their original authors. Source: github.com/ahmadashwah/BenjiePatches.
